1342: 异型卵

题目描述

自从1969年7月16日美国阿波罗11号载人飞船第一次把人类送上月球之后，人类对外太空的探索越来越深入，已经发现了不少太阳系的星球，有的星球也有有生命的活体。这些活体的发现具有重大意义，对人类寻找其他可居住的星球提供了非常有价值的线索。将来有可能各国有可能不止争夺地球的领土，很有可能争夺宇宙中的领土。所以了解外太空的生物的一些习性对将来的研究和发展非常重要。

在ZDM-777星球上发现的休眠异形卵，其外表与常见的卵不同，表面被一层石墨覆盖。当人走近时，那层石墨开始消融，能看到里面的异形卵正在活动。异形卵是如何感知它的寄生处呢？原来，异形卵具备一些热量或压力传感器这些基本的中枢神经系统，通过感知周围的热量，选择热量最大处寄生。因为热量越大异形卵的繁殖速度就越快，（不需要考虑异形卵热死的情况，因为在ZDM-777星球上，温度达不到那个程度）。所有区域的热量可以用一串整数a1,a2,……,an来表示，每个数据对应一个区域。异形卵具有一定的长度L，每个单位长度，对应一个区域。所以异形卵会选择长度等于L的一段连续的区域(ai+ai+1+…+ai+L-1)寄生。但如果某一段长度为L的区域的总热量低于0，异形卵则选择休眠。现在给你一些数据请你找出异形卵的选择。

输入

第一行： K 表示有多少组测试数据。

接下来对每组测试数据有2行，第1行: L N

第2行：a1 a2 …… aN

2≤K≤15 L≤N, 1≤L≤10 1≤N≤100 -100≤ ai≤100

数据之间有一个空格。

输出

对于每组测试数据，输出一行：最适合异形卵寄生的起始位置。若有多处热量和相同，则选择小的起始位置。若无处可以寄生，则输出0。

样例输入 复制 

2
3 5
30 0 100 -30 100
3 5
-100 80 -80 -100 80

样例输出 复制 

3
0
