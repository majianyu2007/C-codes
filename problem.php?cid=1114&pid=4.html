想从磁盘读取数据文件data.dic到Students类型的结构体数组中并完成汇总与分类，主体框架已经完成（可从 http://202.117.179.201/attach/P1567.c 处下载，数据文件可从 http://202.117.179.201/attach/data.dic 处下载），现要求补充完整数据读取LoadFile()、汇总Total()和分类Class()等三个函数后，提交包括框架代码在内的完整程序。

Students结构体的定义为：
typedef struct {

    int Age;         /* 年龄 */

对需要完成的三个函数，说明如下：
  1. 数据读取函数LoadFile(Students *student, int start, int max_len)的功能是读取数据文件中从第start条（从1起始编号）开始的max_len条记录数据到结构体数组student中。
  2. 汇总函数Total(Students *student, int len)的功能是汇总统计大小为len的结构体数组student中所有学生整体及格率和90分以上的优秀率，并列出最高成绩和最低成绩的学生学号与姓名。
  3. 分类函数Class(Students *student, int len)则是按班级（由学号前6位表示）分组输出结构体数组student（数组长度为len）中的学生成绩。
