# C 语言练习与作业合集

本仓库用于整理 C 语言课程示例、作业、OJ 题解与日常练习代码。内容以单文件程序为主，便于直接编译和运行。

## 目录结构
- `2025* /`：按日期归档的练习与作业代码。
- `class/`：课堂示例与小模块（如链表、文件操作等）。
- `oj/`：在线评测题解，按题组或编号分目录，常配套输入样例文件（`.dic` / `.txt`）。
- `accoding/`：按章节/专题整理的练习题。
- `test/`：临时测试与验证程序。
- 根目录脚本：`build-all.sh`、`clean.sh`、`sync-codes.sh`、`collect_codes.py` 等辅助工具。

## 构建与运行
### 编译单个文件
```bash
gcc path/to/file.c -Wall -o path/to/file
# 若使用 math.h，请加 -lm
```

### 批量编译
```bash
./build-all.sh
```
该脚本会递归编译所有 `*.c`，并在需要时自动链接 `-lm`。

### 运行程序
```bash
./path/to/file
```
如需输入文件：
```bash
./oj/1104/A < oj/1104/stud.dic
```

### 清理可执行文件
```bash
./clean.sh
```
仅删除无扩展名的可执行文件，执行前会提示确认。

## 约定与风格
- 语言：C
- 常见格式：4 空格缩进，花括号独占一行（Allman 风格）。
- 文件命名：测试文件多以 `Test*.c` 命名，练习题以题目或功能命名。

## 备注
- 该仓库不依赖特定测试框架，通常通过手工编译和运行验证结果。
- 部分题目配有输入样例文件，请注意使用重定向。

## 建议环境
- `gcc`（支持 `-Wall` 与 `-lm`）
- 类 Unix Shell（bash/zsh）
